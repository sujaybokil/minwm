# Security policy

## Supported versions

minwm is pre-1.0 work-in-progress software. Security fixes are applied to the
latest release and the `main` branch only.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use
[GitHub's private vulnerability reporting](https://github.com/sujaybokil/minwm/security/advisories/new)
and include reproduction steps, affected Windows versions, and likely impact.

Avoid attaching full debug logs unless they are necessary. minwm does not log
window titles, but handles and environment details may still identify a
session.
